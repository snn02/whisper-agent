# Контракт transcript.diarized.json, версия 1

Создаётся только при `diarize: true` / `--diarize`, вместе с выбранными обычными результатами Whisper. Это JSON UTF-8, время — секунды от начала исходного медиа. Имена людей отсутствуют.

| Поле | Значение |
|---|---|
| `schema_version` | Целое `1` |
| `source` | Путь исходного файла относительно входного проекта |
| `language` | Язык распознавания |
| `speakers` | Массив строк `Speaker1`, `Speaker2`, …, в порядке первого появления |
| `turns` | Исходные интервалы pyannote: `start`, `end`, `speaker_id`; могут перекрываться |
| `segments` | Реплики с `id`, `start`, `end`, `text`, `speaker_id`, `words` |
| `segments[].words` | Массив `{start, end, word}`; пустой при отсутствии полного выравнивания слов |

Реплики разделяются при смене назначенного говорящего и на исходных границах Whisper. `segment-1`, `segment-2`, … уникальны только внутри данного файла. Идентификаторы голосов тоже локальны файлу: их нельзя использовать как идентификаторы людей между встречами или повторными запусками.

Слова сопоставляются с `exclusive_speaker_diarization` pyannote. Говорящий назначается только при строгом большинстве длительности слова; ничья, нулевая длительность или недостаточное пересечение дают `speaker_id: null`. Это правило сопоставления, а не вероятность правильного узнавания. Если временные метки слов отсутствуют либо не покрывают текст реплики, сохраняется весь исходный текст с `speaker_id: null`. Текст не выбрасывается ради назначения голоса.

`turns` сохраняет обычную диаризацию с перекрытиями. Единственная метка у слова не означает, что наложенная речь была полностью распознана. Пустые `segments` и `speakers` допустимы для записи без распознанной речи.

Сервис возвращает через MCP и журнал только пути и метаданные. Текст JSON читается из файла отдельным навыком по запросу пользователя. Навык может дополнять исправленную копию именами, сохраняя исходные идентификаторы; он также поддерживает чужие форматы без зависимости от этого контракта.
