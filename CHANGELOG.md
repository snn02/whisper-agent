# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии следуют [SemVer](https://semver.org/lang/ru/).

## Не выпущено

## [1.1.0] - 2026-10-31

Локальная поставка: архив исходников и отдельный архив навыка. Сборка образа, CUDA, загрузка модели, полный Windows-установщик и сквозная диаризация через MCP stdio проверены на синтетической русской записи. Качество на реальной встрече с несколькими участниками и запуск из приложений агента не проверены. Публикация на GitHub не выполнялась.

### Добавлено

- Опциональная диаризация через локальный pyannote с метками `SpeakerN` и файлом `transcript.diarized.json` версии 1; флаг `--diarize` в CLI и параметр `diarize` в MCP.
- Автономный навык `name-speakers` для назначения и уточнения имён в готовых транскриптах разных сервисов, с учётом чата и контекста проекта.
- Независимая установка только навыка без Docker, GPU и npm-зависимостей; выбор проекта, общих навыков или каталога конкретного агента.
- Выбор места установки навыка при установке всего сервиса на Windows.

### Изменено

- Образ дополнен pyannote.audio 4.0.7 и torchaudio; модели диаризации кэшируются между контейнерами, CUDA остаётся обязательной.
- Имена назначаются только отдельным навыком; сервис распознавания сохраняет анонимные метки. Неопределённые назначения не выдаются за подтверждённые.

### Исправлено

- Установка навыка при запуске Windows-установщика из UNC-пути WSL: Node получает файловый путь без префикса провайдера PowerShell.

## До 1.1.0 (ранее не публиковалось)

### Изменено

- MCP запускает только модель `small`; выбор другой модели доступен пользователю через ручной CLI.

### Исправлено

- Подключение OpenCode 2.x записывает лимит выполнения в формате `timeout.execution`.

### Добавлено

- Локальное распознавание медиа проекта через одноразовый Docker-контейнер с NVIDIA GPU и русской моделью Whisper `small`.
- CLI и MCP-инструменты для Codex, Claude Code, локального Cowork и OpenCode.
- Файлы результатов по исходным путям и журнал JSONL без текста распознавания.
- Windows-установщик и инструкции для Windows/WSL.
- Скрипт однокомандного подключения локального MCP к Windows-агентам.
